# ⚔️ Pixel RPS Duel (Камінь • Ножиці • Папір 8-Bit)

Ретро-файтинг та дуельна онлайн-гра в піксельному стилі (8-bit arcade) для **Telegram Mini Apps**, **HTMLBubbles (Widgets)** та звичайних браузерів.

---

## 🎮 Особливості проєкту

* **100% Легально (Без порушень авторських прав):** Класична світова механіка «Камінь-Ножиці-Папір» із авторським ретро-піксельним дизайном.
* **Піксельна 8-bit стилізація:**
  * Шрифти в стилі аркадних автоматів (`Press Start 2P`).
  * Авторські SVG-спрайти кулака, ножиць та паперу.
  * Ефект старого телевізора (CRT Scanlines з можливістю вимкнення).
  * Анімації ударів (punch clash), трясіння екрана та піксельних сердець.
* **Вбудований 8-bit аудіо-синтезатор:** Звуки генеруються на льоту через браузерний `Web Audio API` (біпи, звуки ударів, переможна фанфара) — жодних важких аудіофайлів чи зовнішніх завантажень!
* **3 Ігрові Режими:**
  1. 🤖 **Бій з Ботом:** Соло-тренування з ШІ.
  2. 📱 **1 Телефон (Hotseat):** Гра удвох на одному пристрої з таємним вибором зброї.
  3. 🌐 **Онлайн PvP Дуель:** Синхронізація 2 реальних гравців у реальному часі через серверлесний WebRTC/PeerJS за кодом кімнати або посиланням.
* **Telegram Ready:** Підтримка `Telegram.WebApp` SDK, тактильної вібровіддачі (`HapticFeedback`) та модель оплати через **Telegram Stars (XTR)**.

## 🚀 Як протестувати прямо зараз (Локально)

1. Просто відкрийте файл `index.html` у вашому браузері (Chrome, Firefox, Safari тощо).
2. **Перевірка синхронізації 2 гравців:**
   * Відкрийте `index.html` у **двох різних вкладках** браузера (або у звичайному вікні та вікні інкогніто).
   * У першій вкладці виберіть **«ОНЛАЙН PVP» ➔ «СТВОРИТИ ДУЕЛЬ»**. З'явиться 6-значний код кімнати (наприклад, `542109`).
   * У другій вкладці виберіть **«ОНЛАЙН PVP»**, введіть цей код та натисніть **«ПРИЄДНАТИСЯ»**.
   * Обидві вкладки миттєво синхронізуються: виберіть зброю в кожній і подивіться на одночасний бій та анімацію удару!

## 📦 Як опублікувати на GitHub & GitHub Pages

Щоб гра працювала в Telegram за прямим посиланням:

1. **Створіть новий репозиторій на GitHub** (наприклад, `pixel-rps-duel`).
2. У терміналі папки проєкту виконайте:
   ```bash
   git add .
   git commit -m "feat: Initial commit of Pixel RPS Duel"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/pixel-rps-duel.git
   git push -u origin main
   ```
3. **Увімкніть безкоштовний хостинг GitHub Pages:**
   * Зайдіть у свій репозиторій на GitHub ➔ **Settings** ➔ **Pages**.
   * У розділі **Branch** виберіть `main` і натисніть **Save**.
   * За 1–2 хвилини гра буде доступна за адресою:  
     `https://ВАШ_ЛОГІН.github.io/pixel-rps-duel/`

## 🤖 Підключення до Telegram Бота

У проєкті є готовий скрипт `bot.py` на базі `aiogram 3.x`:
1. Встановіть бібліотеку:
   ```bash
   pip install aiogram
   ```
2. Відкрийте `bot.py` та вкажіть ваш `BOT_TOKEN` (отриманий у `@BotFather`) і посилання на гру з GitHub Pages:
   ```python
   BOT_TOKEN = "ваш_токен_від_BotFather"
   GAME_WEBAPP_URL = "https://ваш_логін.github.io/pixel-rps-duel/"
   ```
3. Запустіть бота:
   ```bash
   python bot.py
   ```
4. У чаті з ботом надішліть `/start` — з'явиться кнопка запуску гри та кнопка купівлі квитків за Telegram Stars!

## 💰 Структура монетизації

* **Telegram Stars (XTR):** Квитки на турніри, покупка додаткових спроб («життів») або відкриття особливих скінів для кулаків/зброї.
* **P2P Ставки:** Можливість двом гравцям у груповому чаті грати на фіксовану кількість зірок Telegram.
